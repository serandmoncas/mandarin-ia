# mandarin-ia

App para aprender mandarín con IA: vocabulario por frecuencia, repaso espaciado (FSRS),
entrenamiento de tonos, reconocimiento de caracteres y conversación de viaje — en español.

Meta inicial: conversar en viajes y certificar HSK 3.0 + HSKK a principios de 2028.
